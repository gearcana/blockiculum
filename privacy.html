Summary

The BLOCKICULUM publishing tool is a private, single-operator desktop application. It signs in to one YouTube account — the one that owns the BLOCKICULUM channel — so that it can upload that channel's own videos. It has no other users, collects no personal data from anyone, and sends nothing to any third party.

Who this covers

This policy covers two things: the BLOCKICULUM publishing tool (the desktop application that requests Google OAuth access), and this website.

The publishing tool

What it accesses

With your explicit consent, the tool requests these Google API scopes:

  • youtube.force-ssl — to upload videos to the channel you sign in with, and to set their title, description, tags, thumbnail and visibility.
  • yt-analytics.readonly — to read that channel's own performance figures, so the tool can report on videos it published.

It uses no other scopes. It does not read, modify or delete anything outside the channel you authorise, and it cannot access other Google services.

What it stores, and where

  • An OAuth token for the authorised channel, stored only in a local file on the operator's own computer. It is never transmitted anywhere except to Google, and never committed to source control.
  • A local upload log — video ids, titles and timestamps of uploads the tool made — used to respect the YouTube API's daily quota.

There is no server, no database and no analytics service. Nothing is stored off the operator's machine.

What it never does

  • It does not collect data about viewers, subscribers or any other person.
  • It does not sell, share or transfer data to anybody.
  • It does not use Google user data for advertising, profiling or training models.
  • It is not offered to other users; there are no accounts to create.

Google API Services User Data Policy

The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be withdrawn at any time at myaccount.google.com/permissions. Deleting the local token file also ends the tool's access immediately. Revoking access does not delete videos already published to the channel.

Retention

The token is kept until it is revoked or the local file is deleted. The upload log is kept on the operator's machine for quota accounting and can be deleted at any time.

This website

These pages are static files hosted on GitHub Pages. They set no cookies, run no analytics and ask for no information. GitHub, as the host, may log standard request data such as IP addresses; see GitHub's privacy statement.

Children

BLOCKICULUM's videos are made for young learners, but this tool and this website are not directed at children and collect no information from them. Viewing happens on YouTube, under Google's own privacy policy.
